Sintaxe Java

Repositório dedicado aos meus estudos de **Java**, com foco no aprendizado da sintaxe da linguagem e na prática dos fundamentos da programação.

Este projeto reúne exercícios e exemplos desenvolvidos durante minha jornada de aprendizado, com o objetivo de fortalecer a lógica de programação e construir uma base sólida para o desenvolvimento Backend com Java.

Conteúdos estudados

- **Variáveis e tipos de dados:** declaração, atribuição e utilização de variáveis.
- **Operadores:** aritméticos, relacionais, lógicos e de atribuição.
- **Estruturas básicas:** organização de classes e método `main`.
- **Métodos:** criação, parâmetros, argumentos e retorno de valores.
- **Escopo de variáveis:** variáveis locais e sua visibilidade.
- **JavaDoc:** documentação de classes e métodos.

Exercícios práticos

O repositório também contém exercícios para aplicar os conceitos estudados, incluindo:

- Cálculo do dobro de um número.
- Cálculo de média de notas.
- Verificação de aprovação.
- Operações matemáticas com métodos.
- Conversão de horas de estudo em minutos.

Tecnologias utilizadas

- Java
- IntelliJ IDEA

 Objetivo

Desenvolver minhas habilidades em Java, praticar a resolução de problemas e consolidar os fundamentos necessários para avançar nos estudos de **Java Backend**, especialmente com Spring Boot.

Evolução dos estudos

Este repositório faz parte da minha jornada de aprendizado e será atualizado conforme eu avançar nos estudos e desenvolver novos exercícios e projetos.
